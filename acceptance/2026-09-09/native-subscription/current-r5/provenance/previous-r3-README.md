# Actual native Claude subscription qualification

The operator's Claude Max login works with Claude Code 2.1.267. The current archive in artifact.json uses native authentication only in its trusted parent and forwards to the fixed native Anthropic endpoint. The guest receives an ephemeral relay credential. No account cache or bearer token is included here.

Current r3 cases passed seven approval stages, capability/credential revocation, in-flight revocation, killed/malformed/timed-out kernel responses, six explicit startup refusals, three evidence substitutions, concurrent-owner exclusion and separate forbidden read/write denial. Signed owner recovery retained the original uncertain operation, rejected a forged owner record with the exact signature error, imported a valid signed completion, required explicit receipt/ACK and then performed one native read without repeating the write. Each native case checks actual host tool attempts and independently observes resource and audit volumes.

Some ordinary test prompts caused the model to refuse before attempting the tool. Those attempts remain failed coverage. The later forbidden-write and approval-resume cases use the actual provider's documented tool_choice for an already declared tool. The driver does not change arguments or manufacture assistant output, and each selection is retained in its tool-choice log. The actual native arguments, results and resource effects still determine pass/fail.

The initial subscription archive allowed its native OAuth header to be forwarded to an explicitly selected localhost fixture origin. Review found and repaired that implementation defect; real provider tests unset that override and no actual leak was observed. Current r3 also canonicalizes native-login and supervisor module imports. Earlier archives and their evidence are retained separately and are not current qualification.

Current r3 final useful/delivery/crash/cancellation tests are still in progress. This record does not establish full I01-I08 acceptance or publication. Historical fixture and hook-only results remain distinct.
